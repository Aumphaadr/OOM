# Дизайн: сцена «Объёмы» (изометрия, без WebGL)

Стереометрию ждут серии 03/56 (объём = кубики, экструзия-лесенка
отрезок → прямоугольник → кубоид, «множитель за этаж») и 39 (подобие: k³
авансом). Решение зафиксировано в design-plane.md §5: изометрическая
проекция на нашем Canvas 2D, фиксированный ракурс, как у чертёжников
на клетчатой бумаге. Красивое крутящееся 3D — Blender (видеоряд).

## 1. Главная идея: третья ступень экструзии

Сцена «Площади» растит отрезок в прямоугольник кромкой. Здесь та же
лесенка делает ещё один шаг: **отрезок (w) → площадка (w×d) → кубоид
(w×d×h)**. Один объект, три состояния — нулевые размеры честно значат
«этого измерения ещё нет». Объём читается «по этажам»: этаж = w·d
кубиков, этажей h — множитель за этаж, никакой формулы с потолка.

## 2. Объект ядра

```ts
interface CuboidObject extends ObjectBase {
  kind: 'cuboid';
  label: string;        // К1, К2…
  w: Rational; d: Rational; h: Rational;  // d=h=0 — отрезок, h=0 — площадка
  showW/showD/showH/showVolume: boolean;  // подписи прячутся преподом
}
```

- `spawnCuboid(w, d, h)`, размеры — целые клетки (кубики не половинятся),
  w ∈ [1..12], d, h ∈ [0..10].
- `setCuboidSize(id, w, d, h, commit)` — транзиент + один коммит в журнал
  (как кромка площадей), событие `cuboid-changed {note}`, сквозной undo.
- Молоток ×k/÷k по кубоиду: все РЁБРА ×k. Заметка честно называет
  множитель по числу живых измерений: длина ×k / площадь ×k² / объём ×k³ —
  лесенка серии 39 живьём. Отказы как у фигур: не поместится / сожмётся.
- Резов и склеек в MVP нет (дистрибутивность уже показана на площадях).

**Цели**: `cuboid-size {w, d, h}` и `cuboids-size {list}` (несколько тел).

## 3. Сцена «Объёмы» (id 'space')

- Изометрия: (x, y, z) → экран (x−y)·0.866·s, (x+y)·0.5·s − z·s;
  z вверх, ракурс фиксирован, камера не вращается.
- Кубоид = три видимые грани (верх светлее, фронт средне, бок темнее)
  с сеткой единичных кубиков по каждой грани; слои читаются глазами.
- Три ручки-кромки: ширина, глубина, высота — перетаскивание с проекцией
  курсора на ось, снап к целым. Тянуть за грань — перенос всего тела
  (scenePos, презентация).
- Молоток в руке → удар по телу (ctx.hit → scaleCuboid), ПКМ роняет.
- Панель: поля w/d/h + «Кубоид» (construct), галки подписей размеров
  и объёма. Подпись объёма — по этажам: «V = (4×3)·2 = 24 кубика».

## 4. Глава «Объёмы: этажи из кубиков»

- vol-01: дострой отрезок 4 до кубоида 4×3×2 (две экструзии кромками).
- vol-02 ⭐: 999 про «почему перемножить»: этаж 5×4 = 20 кубиков, этажей 3;
  контрпример «сложить 5+4+3» бьётся одним этажом (уже 20 > 12);
  обстрел: сплющи в 5×4×0 — у плоскости нет ни одного кубика.
- vol-03 ⭐: лесенка масштаба: ×2 по отрезку/площадке/кубоиду —
  ×2, ×4, ×8 на одной доске; обстрел ÷2 назад.

## 5. Не делаем в MVP (кандидаты на витки)

- Сечения-«томограф» (подсветка среза) — серия 57, отдельным витком.
- Наклонные тела, цилиндр/конус (переливание = Blender-видео).
- Развёртки, скрещивающиеся прямые.
- Вращение камеры — принципиально нет (фиксированный чертёжный ракурс).
