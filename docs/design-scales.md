# Дизайн: неизвестная (запертая коробка) и сцена «Весы»

Задача: уравнение как равновесие, решение как «отмотка» инструментов (темы 011 и 014
из theme_line), неизвестная как запертая коробка с определённым, но скрытым значением.
Референсы: [каталог сцен §5 и «Неявные объекты»](../../idea/scenes.md).

## 1. Новый тип объекта: неизвестная

```ts
interface UnknownObject extends ObjectBase {
  kind: 'unknown';
  name: string;            // буква: x, y, a…
  readonly secret: Rational; // значение существует и определено — просто заперто
  ops: { op: ToolOp; n: Rational }[]; // стопка «наклеек»: операции, применённые к коробке
  revealed: boolean;       // коробка открыта (стопка снята до дна)
}
```

Ключевая идея представления: применённые операции — это **наклейки, навешанные на
коробку стопкой** (x → [×2] → [+3] верхняя). Никакого парсинга выражений: снять можно
только верхнюю наклейку, и только точным обратным инструментом. Для субтитров выражение
собирается из стопки текстом: «(x × 2) + 3».

## 2. Правило сцены, зашитое в физику

Молоток в сцене «Весы» **бьёт только по обеим чашам сразу** — принцип «одинаковые
инструменты по одинаковым объектам сохраняют одинаковость» (тема 011) не проговаривается,
а не может быть нарушен. Применение одного удара:

- правая чаша (число) меняется как обычно: 7 → 14;
- левая чаша (коробка): если инструмент — точный обратный к ВЕРХНЕЙ наклейке,
  наклейка снимается (равносильный переход «назад»); иначе — новая наклейка сверху.

Стопка снята до дна → коробка распахивается: секрет виден, и он равен числу на правой
чаше — «x = 7, сходится». Это не проверка, а неизбежность (баланс — инвариант), но
эмоционально это финал: замок щёлкнул.

Один удар = **одна транзакция в журнале** (обе чаши в одной записи) — Ctrl+Z отматывает
шаг уравнения целиком, а не половинку.

## 3. Драматургия урока

1. Преподаватель создаёт уравнение: панель сцены → секрет (например 7) и буква → на левой
   чаше появляется запертая коробка [x], на правой — число 7 (пока тривиально: x = 7).
2. Преподаватель «запутывает» ударами: ×2 → «x·2 = 14», +3 → «(x·2)+3 = 17».
   (Ученик этого не видит — или видит, если цель «показать, как уравнения устроены».)
3. Ученик решает: подбирает молотки-инверсы. −3 снимает верхнюю наклейку → «x·2 = 14»;
   ÷2 → «x = 7», коробка открывается.
4. Ошибочный молоток не ломает ничего: −5 вместо −3 просто добавит наклейку
   (и правую чашу изменит) — назад можно тем же способом или Ctrl+Z. Тупик со смыслом:
   удар «x²» добавит наклейку, которую снять НЕЛЬЗЯ (у x² нет обратного) —
   первое живое «зачем следить за равносильностью».

## 4. Границы MVP

- Одно уравнение на сцене за раз (новое «Создать» заменяет старое, с подтверждающей
  записью в историю).
- Неизвестная только на левой чаше, число — на правой; никаких «x с обеих сторон»
  (это следующий виток: 2x+3 = x+10 требует переноса — отдельная механика).
- Сцена скрывает панель «Объекты» (sidebar: objects: false), молотки — общие.
- Отказ инструмента (√ от отрицательной правой части) отклоняет весь удар — обе чаши
  нетронуты («к обеим частям применить нельзя — значит, нельзя вообще»).
- После открытия коробки удары не принимаются: подсказка «уравнение решено — создай новое».
- Неизвестная в других сценах не отображается (фильтры по kind уже стоят).
