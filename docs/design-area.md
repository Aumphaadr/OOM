# Дизайн: сцена «Площади» (первый виток геометрии)

Темы theme_line, которые закрывает: 018 (площадь прямоугольника), 019 (алгебра
в геометрическом смысле), 026 (ФСУ), и честная демонстрация распределительного
свойства из 009 — a·(b+c) = a·b + a·c, которое на конвейере показать нельзя.
Референсы: [каталог сцен](../../idea/scenes.md), демо экструзии из
[манифеста ООМ](../../idea/OOM.txt).

## 1. Объект: прямоугольник (и отрезок как его вырожденный случай)

```ts
interface RectObject extends ObjectBase {
  kind: 'rect';
  label: string;            // П1, П2…
  w: Rational;              // ширина в попугаях (клетках)
  h: Rational;              // высота; h = 0 — это ОТРЕЗОК
  cutsX: Rational[];        // вертикальные резы: абсолютные позиции 0 < x < w
  cutsY: Rational[];        // горизонтальные резы: 0 < y < h
}
```

Ключевые решения:

- **Отрезок — это прямоугольник нулевой высоты.** Экструзия («умножить отрезок
  на высоту») — не метафора, а буквальный жест: потянул верхнюю кромку вверх —
  1D стал 2D. Обратный жест (сплющить до нуля) показывает вырождение.
- **Резы — в абсолютных попугаях**, а не долях (в отличие от лент): при
  растягивании фигуры рез остаётся на «x = 3», и сегменты сторон пересчитываются.
  Рез — точка на стороне, та же философия «рез = точка».
- Сетка резов — по целым клеткам (MVP), экструзия — со снапом к 1/2.

## 2. Главное демо сцены: площадь как произведение и его разложение

Прямоугольник 5×3 стоит на клетчатом фоне (наша сетка из «Коробок» наконец
работает по назначению): стороны подписаны снизу и слева, площадь — в центре: 15.

- **Вертикальный рез** на x = 3 делит его на 3×3 и 2×3; подписи площадей 9 и 6,
  подписи сегментов ширины «3» и «2». Картинка читается как формула:
  **(3 + 2)·3 = 3·3 + 2·3** — распределительное свойство без единого слова.
- **Рез в обе стороны** у квадрата 7×7 (x = 4, y = 4) даёт четыре куска:
  16, 12, 12, 9 — **(4+3)² = 4² + 2·4·3 + 3²** — формула квадрата суммы
  как разглядывание картинки. Тема 026 из одного жеста.
- Склейка — кликом по резу, как у лент.

## 3. Жесты (грамматика — общая с остальными сценами)

| Жест | Действие |
| --- | --- |
| потянуть верхнюю кромку | экструзия/изменение высоты (транзиентно, коммит на отпускании — как ползунок переменной) |
| потянуть правую кромку | изменение ширины |
| клик по линии сетки внутри фигуры | рез (вертикальный или горизонтальный — по ближайшей линии) |
| клик по резу | склейка |
| хватание за тело | перенос фигуры |
| клик | выделение; Shift — группа; Delete/✕ — удаление |
| клик мимо швов? | здесь НЕ карточка: все настройки фигуры — жестами; карточка не нужна |

Курсорные подсказки: кромки — `ns-resize`/`ew-resize`, тело — `grab`,
сетка внутри — `pointer`.

Молотки по фигуре — честный отказ сигнатуры («бьёт только по числам»):
фигуры меняются жестами. Мост «фигура → число» (инструмент «измерить площадь»,
порождающий число) — виток 2, не MVP.

## 4. Ядро и журнал

Операции Session (всё через журнал, с undo и субтитрами):

- `spawnRect(w, h)` / `spawnSegment(len)` (= spawnRect(len, 0));
- `setRectSize(id, w, h, commit)` — транзиентная протяжка + один коммит
  (механика как у переменной: база до протяжки, одна запись в лог);
- `cutRect(id, axis, pos)` / `mergeRect(id, axis, pos)`;
- субтитры: «П1: 5×3, площадь 15», «П1: рез x=3 → 9 | 6»,
  «П1: экструзия 5×0 → 5×3» — протокол эксперимента сохраняется.

Undo-состояние: {w, h, cutsX, cutsY}. Сериализация — по образцу лент.

## 5. Цели упражнений

Новый вид цели: `{ kind: 'rect-pieces'; areas: string[] }` — площади кусков
построчно (снизу-слева направо): для ФСУ-квадрата `["16","12","12","9"]`.
Плюс `{ kind: 'rect-size'; w: string; h: string }` — «вытяни отрезок 5 в
прямоугольник 5×4». Обе — предикаты над сессией, как всё в goal.ts.

## 6. Границы MVP (сознательно НЕ входит)

- **3D/объём** (экструзия прямоугольника в кубоид с изометрией) — виток 2;
  в MVP только 1D → 2D.
- **Параллелограммы и «честная высота»** — виток 3, со страховкой
  «площадь = основание × высота, а не × боковая сторона» (см. предупреждение
  в анализе theme_line). До тех пор — только прямоугольники: на них ошибку
  сделать невозможно.
- Произвольные (нецелые) резы, повороты, измерение в число — позже.

## 7. Контент, который сцена отпирает

Главы: «Площадь: сколько клеток внутри» (018), «Скобки на клетчатой бумаге»
(дистрибутивность, 009/019), «Квадрат суммы» (026, ⭐). Упражнения: экструзия
отрезка по заданной площади, рез под формулу, восстановление формулы по картинке.
