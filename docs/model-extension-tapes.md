# Дизайн: типы объектов и сцена «Ленты»

Задача: ввести в модель первый нечисловой объект (лента) так, чтобы этот же механизм
потом принял фигуры, углы и тела без переделки ядра. Референс поведения лент —
[../../idea/scenes.md](../../idea/scenes.md), §«Сцена 4».

## 1. Объекты становятся размеченным объединением (kind)

```ts
interface ObjectBase { id; scenePos }                    // общее: идентичность и карманы сцен

interface NumberObject extends ObjectBase {              // то, что было MathObject
  kind: 'number'; value: Rational; trail: Rational[];
}

interface TapeObject extends ObjectBase {
  kind: 'tape';
  whole: Rational;        // длина целого (в условных единицах сцены)
  unit: string;           // подпись целого: '', 'км', 'миля' — «доля ЧЕГО-ТО»
  mode: number | null;    // режим деления /n (null — целая лента без швов)
  cuts: number[];         // выполненные резы: индексы швов 1…n−1, отсортированы
}

type MathObject = NumberObject | TapeObject;
```

Будущие типы (фигура, угол, тело) добавляются новыми членами объединения —
существующий код не меняется, TypeScript сам потребует обработать новый kind
только там, где это нужно.

## 2. Сигнатуры инструментов начинают работать по типам

Числовые молотки («+5», «×(−1)») применимы только к `kind: 'number'`; попытка ударить
по ленте даёт честный отказ через журнал («этот инструмент бьёт только по числам») —
тот самый принцип «нельзя — это свойство инструмента».

Операции над лентами — НЕ молотки, а жесты сцены (клик по шву), как в исходном
описании. Но жест обязан пройти через ядро:

```ts
session.cutTape(id, seam)     // рез по шву
session.mergeTape(id, seam)   // склейка по резу (клик по уже сделанному резу)
session.setTapeMode(id, n)    // смена режима: /6 → /12 пересчитывает резы (дорез);
                              // /6 → /3 допустима, только если все резы делятся (склейка)
```

Каждая операция валидируется, пишется в общий журнал (undo работает через снапшоты
состояния {mode, cuts}) и порождает событие с готовой строкой для субтитров:
«лента (1 км) /6: рез по шву 2 → куски 2/6 | 4/6». Протокол эксперимента сохраняется.

## 3. Сцены объявляют, что умеют показывать

«Коробки», «Прямая» и «Конвейер» показывают только `number`-объекты (ленты для них
невидимы), сцена «Ленты» — только `tape`. Мост между мирами (лента под числовой
прямой, «измерить кусок» → число) — отдельный шаг, не этот.

## 4. MVP сцены «Ленты»

- Панель сцены: длина целого (понимает дроби), подпись единицы, режим /n → «Создать ленту».
- Ленты стопкой с общей левой кромкой; ширина = длина × масштаб; подпись целого справа.
- Наведение на ленту показывает еле заметные швы её режима; клик по шву — рез,
  клик по существующему резу — склейка (пунктирное/бледное = потенциал, сплошное = факт —
  та же грамматика, что у обводок).
- Подписи кусков между резами: «2/6», «4/6» (мелкие куски подпись прячут).
- Бейдж режима «/6» слева от ленты: клик — дорезать вдвое (/12), ПКМ — склеить вдвое (/3),
  если все резы это позволяют; иначе отказ в субтитры.
- Вертикальная линейка-просвет на x курсора через все ленты — сравнение «на глаз»
  без веры на слово (2/12 против 1/6).
- Undo общий: отматывает и резы, и режимы, и удары по числам — один журнал.

Отложено сознательно: отделяемые куски (перенос 1/6 на другую ленту), связь с числовой
прямой, эквивалентность в субтитрах («2/12 = 1/6») — следующие итерации.
