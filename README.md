# ООМ — Объектно-ориентированная математика

Открыть онлайн: [https://aumphaadr.github.io/OOM/](https://aumphaadr.github.io/OOM/)

Лечебный курс школьной математики (3–11 классы) для учеников со слабыми навыками
и интерактивная доска к нему.

Ядро подхода — чтение математики через призму ООП: есть **математические объекты**
(число, дробь-лента, неизвестная-коробка) и **математические инструменты** («молотки»:
+5, ×(−1), √, рез ленты), меняющие их состояние. Запись «5 + 3» читается асимметрично:
объект 5, по которому бьют инструментом «+3». Такой сдвиг фокуса — с правил («как надо
делать») на принципы («как это устроено») — позволяет закрывать пробелы, которые
классическая подача оставила: ученик ставит эксперимент, наблюдает закономерность,
формулирует вывод сам и проверяет его на граничных случаях.

ООМ не заменяет школьную программу и ФГОС/ФРП — он лечит и достраивает.

## Быстрый старт приложения

```bash
npm install
npm run dev      # http://localhost:5173
```

Десять сцен:

- **Коробки** — значение и изменение: молоток бьёт, коробка меняется;
  переменная — коробка с именем, своей записью значения (десятичной
  или дробью) и значением, которое можно спрятать;
- **Числовая прямая** — положение, прыжки, зум, мультипредставления записи;
- **Плоскость** — адреса точек; панель «Функции»: формулы вида
  «x^2 − 2(x+5) + 10» с выбором цвета и анимацией порождения следа
  по точкам, жест «прогони вход» кликом по оси; чтение следов:
  проколы-корни, выше/ниже оси, точки встречи, секущая-крутизна,
  клетки под следом; векторы с суммой «хвост к носу»; движения:
  переносы, зеркала, повороты на 90°, гомотетия; фигуры: полигоны
  и круги с точной площадью, периметром и углами при вершинах;
- **Конвейер** — функция-машина: композиция, реверс, чёрный ящик,
  кольцо-прогрессия;
- **Ленты** — дроби как длины: «рез = точка, режим = линейка», эталонная
  единица;
- **Площади** — отрезок → прямоугольник экструзией, резы, дистрибутивность
  и ФСУ картинкой;
- **Объёмы** — изометрия без WebGL: отрезок → площадка → кубоид, объём
  по этажам, масштаб ×k → k/k²/k³, томограф-срезы;
- **Столбики** — набор чисел: переливание с суммой-инвариантом, среднее =
  «перелить поровну», шеренга и медиана;
- **Окружность** — угол как раствор поворота, высота-синус и тень-косинус,
  честная намотка за 360°, размотка в волну с семействами решений, вторая
  линейка-радианы;
- **Весы** — уравнение как равновесие: качающееся коромысло, удары по чашам,
  x с обеих сторон.

Учебник (кнопка с книгой в шапке): 45 глав, 110 интерактивных упражнений
с целями-предикатами, подсказками и счётчиком ходов; в 51 из них — цикл
«чекпоинт → контрпример → обстрел границ» с копилкой диагнозов. Контент лежит
в `public/textbook/` и правится без пересборки.

## Принципы, на которых всё держится

- **Точная арифметика**: модель хранит рациональные числа (bigint), float — только
  на экране; приближения (√8 ≈ 2,828) всегда помечены знаком «≈».
- **Журнал событий**: всё меняется через ядро и разлетается подписчикам (сцены,
  история, цели упражнений, будущая диагностика). Undo — сквозной.
- **Честные отказы**: «делить на ноль нельзя» — свойство инструмента, а не запрет
  учителя; необратимость x² видна физически (реверс конвейера клинит, наклейка
  не снимается).
- **Прибамбасы по запросу**: история, шлейфы значений, швы лент и настройки
  показываются только когда пользователь попросил.
- **Урок — данные, не код**: пресеты доски и упражнения — JSON; «сохранить доску
  как упражнение» встроено (пункт «Заготовка упражнения — в буфер» в меню доски).

## Разработка

```bash
npm run dev        # дев-сервер
npm run test       # смоук-тесты: ядро, решаемость всего задачника, DOM (vitest)
npm run typecheck  # tsc --noEmit
npm run build      # проверка типов + сборка в dist/
npm run icons:sync -- <путь к Klaarheid-Icons>  # обновить значки из набора
```

Архитектура: точное ядро (`src/core/` — Rational на bigint, журнал событий
Session, цели-предикаты), сцены-плагины (`src/scenes/`), оболочка и читалка
(`src/ui/`), значки (`src/icons/`), контент учебника — статика (`public/textbook/`).
Каждое новое упражнение обязано получить решатель в `tests/exercises.test.ts` —
смоук-тест проверяет решаемость всего задачника, включая контрпримеры и обстрелы.
Дизайн-решения сцен — в `docs/design-*.md`, порядок правок и проверок —
в [CONTRIBUTING.md](CONTRIBUTING.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

## Статус (сентябрь 2026)

Работает: доска с десятью сценами, учебник с задачником и чекпоинтами-диагностикой
(методика «опасных случаев»), комбо-инструменты, переменная — коробка с именем
(на «Числовой прямой» — ползунок), фигуры на «Плоскости», глобальные настройки,
сохранение/загрузка доски (в localStorage и файлом), сквозной undo вплоть
до создания и удаления объектов, запираемые упражнения (без читерства кузницей),
смоук-тесты `npm run test` (vitest: ядро, решаемость всего задачника, DOM, значки).
Дальше по плану: режим домашки с пулом задач и код-ссылками, мост
«лента под числовой прямой», тач-поддержка.
