# ООМ — Объектно-ориентированная математика

Открыть онлайн: [https://aumphaadr.github.io/OOM/](https://aumphaadr.github.io/OOM/)

Лечебный курс школьной математики (3–11 классы) для учеников со слабыми навыками
и интерактивная доска к нему.

Ядро подхода — чтение математики через призму ООП: есть **математические объекты**
(число, дробь-лента, неизвестная-коробка) и **математические инструменты** («молотки»:
+5, ×(−1), √, рез ленты), меняющие их состояние. Запись «5 + 3» читается асимметрично:
объект 5, по которому бьют инструментом «+3». Такой сдвиг фокуса — с правил («как надо
делать») на принципы («как это устроено») — позволяет закрывать пробелы, которые
классическая подача оставила: ученик ставит эксперимент, наблюдает закономерность,
формулирует вывод сам и проверяет его на граничных случаях.

ООМ не заменяет школьную программу и ФГОС/ФРП — он лечит и достраивает.

## Быстрый старт приложения

```bash
npm install
npm run dev      # http://localhost:5173
```

Сцены: **Коробки** (значение и изменение), **Числовая прямая** (положение, прыжки,
зум), **Плоскость** (адреса точек, следы инструментов — график = след молотка,
взятого в руку, жест «прогони вход» — и стрелки-команды с суммой «хвост к носу»),
**Конвейер**
(функция-машина, композиция, реверс, чёрный ящик, кольцо-прогрессия), **Ленты**
(дроби как длины, «рез = точка, режим = линейка», эталонная единица), **Площади**
(отрезок→прямоугольник экструзией, резы, дистрибутивность и ФСУ картинкой),
**Объёмы** (изометрия без WebGL: отрезок→площадка→кубоид, объём по этажам,
масштаб ×k → k/k²/k³), **Столбики** (набор чисел: переливание с суммой-инвариантом,
среднее = «перелить поровну», шеренга и медиана), **Окружность** (угол =
раствор поворота, высота-синус и тень-косинус, честная намотка за 360°,
размотка в волну с семейством решений, вторая линейка-радианы),
**Весы** (уравнение как равновесие, качающееся коромысло, удары по чашам,
x с обеих сторон).

Учебник (кнопка 📖): 44 главы, 105 интерактивных упражнений с целями-предикатами,
подсказками и счётчиком ходов; 47 циклов «чекпоинт → контрпример → обстрел границ»
с копилкой диагнозов. Контент лежит в `public/textbook/` и правится
без пересборки.

## Принципы, на которых всё держится

- **Точная арифметика**: модель хранит рациональные числа (bigint), float — только
  на экране; приближения (√8 ≈ 2,828) всегда помечены знаком «≈».
- **Журнал событий**: всё меняется через ядро и разлетается подписчикам (сцены,
  история, цели упражнений, будущая диагностика). Undo — сквозной.
- **Честные отказы**: «делить на ноль нельзя» — свойство инструмента, а не запрет
  учителя; необратимость x² видна физически (реверс конвейера клинит, наклейка
  не снимается).
- **Прибамбасы по запросу**: история, шлейфы значений, швы лент и настройки
  показываются только когда пользователь попросил.
- **Урок — данные, не код**: пресеты доски и упражнения — JSON; «сохранить доску
  как упражнение» встроено (кнопка 📤).

## Статус (август 2026)

Работает: доска с десятью сценами, учебник с задачником и чекпоинтами-диагностикой
(методика «опасных случаев»), комбо-инструменты, переменная-ползунок,
